# Semiconductor × Defence Lab

An interdisciplinary exploration workspace for combining semiconductor engineering, embedded systems, electronics, and defence technology.

## Purpose

This repository is currently an **R&D and brainstorming space**, not a finalized product.

The goal is to:

- identify meaningful defence problems where semiconductor technology can contribute
- research existing approaches and technical constraints
- explore feasible FY-level proof-of-concepts
- document ideas, experiments, references, and decisions
- eventually develop a structured project proposal for faculty validation

## Working Questions

1. What real defence problem are we trying to solve?
2. Where does semiconductor technology provide a genuine advantage?
3. What can realistically be prototyped during first year?
4. What hardware, software, fabrication, and laboratory resources are available?
5. What requires faculty or Skill Centre validation?
6. What would a measurable proof-of-concept look like?
